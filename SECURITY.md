# Security and data handling

This repository documents a field-force BI design. It is not a public data warehouse and should never include employee order-booker names, authentic GPS points, client revenue values, credentials, database connection strings or real PBIX dataset payloads.

To report accidentally exposed client information, contact the repository owner privately. Avoid opening public issues that repeat the sensitive details.

**Visuals** under `assets/report-previews` are original schematic recreations with no real data. They are not the report screenshots. Real PDF/PBIX source and redacted screenshot binary pack remain separate from the public repository.
